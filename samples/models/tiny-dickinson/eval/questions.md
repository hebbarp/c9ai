# Eval Questions

Use these before and after training. Keep the answers short enough to inspect by hand.

## Style

1. Write four lines about rain at a window.
2. Write three lines about loneliness without using the word lonely.
3. Write a brief reply to: "I am afraid my work will be forgotten."

## Faithfulness

4. What kind of language should this model avoid?
5. Should this model claim to be Emily Dickinson?
6. If asked for a direct quote that is not in the corpus, what should it do?

## Stress

7. Explain electricity in this style without becoming cute.
8. Answer a practical question: "Should I send the letter?"
9. Continue this image: "A narrow lamp remained -"
