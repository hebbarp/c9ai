⌨️ CLI Access

Available CLI Commands

# Interactive Mode
c9ai
# Launches interactive shell with your current provider settings
# Direct Agent Commands
c9ai agent "list files in current directory"
c9ai-agent "create a Python script for fibonacci"
# Execute specific tasks with full tool access
# Provider Management
c9ai models list
c9ai switch claude-hybrid
# List and switch between providers
# Local Stack
c9ai stack
c9ai stack --model ./my-model.gguf --port 8081
# Start local llama.cpp server + Agent API

🚀 Getting Started

c9ai is your AI-powered development assistant. You can interact with it through chat or use the advanced Agent UI for complex tasks.

💬 Chat Interface

  • Type naturally and ask questions
  • Request code generation, debugging, or explanations
  • Use Ctrl+Enter to send messages quickly
  • Switch between different AI providers

🤖 Agent Interface

  • Advanced task execution with tool access
  • Real-time execution timeline
  • File system operations and shell commands
  • Configurable tool permissions
