# Corpus

Add a small, verified public-domain Dickinson corpus here.

Start small:

- 20 to 50 short poems
- one poem per markdown or text file
- source/provenance noted at the top of each file
- no modern copyrighted annotations or introductions

Recommended file shape:

```text
Title: <poem title or first line>
Source: <public-domain source URL or book citation>
License: public domain

<poem text>
```

Do not train on text whose license you cannot explain.
